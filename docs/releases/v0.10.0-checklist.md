# Release Checklist — v0.10.0

RC: v0.10.0-rc.1 (2026-10-02), commit `41f02c9`

Delivered since v0.9.0 (2026-03-16): `node-24-support`, `fix-ts-addons-esm-projects`, `esm-output-check`. The
release notes are `Release-Notes.md` `## [Unreleased]`, which becomes `## [0.10.0]` in the final release.

## Verification

- [ ] node-24-support — websmith is built and tested on Node 24; published packages declare
      `engines.node: ">=22.12"`, Node 20 is no longer supported (**Breaking**).
- [ ] fix-ts-addons-esm-projects — TypeScript addons load in projects whose `package.json` declares
      `"type": "module"` (#111); the CLI writes compiled addons to `.websmith-cache/addons-cli` next to
      `tsconfig.json` instead of `lib/` next to the addons directory.
- [ ] esm-output-check — the per-profile `esm` option (`runtime`, `check`, `ignore`) reports ESM problems in emitted
      JavaScript, including addon-generated code, with the source file, profile and addons in each diagnostic.
- [ ] esm-output-check — `websmith` exits non-zero on error-level diagnostics, including TypeScript errors that
      previously only printed (**Breaking**).
- [ ] esm-output-check — the webpack loader fails the build for syntax, declaration-emit and configuration errors
      and ESM check findings, not type errors (**Breaking**).
- [ ] Smoke test in a `"type": "module"` project on Node 24: CLI build with a profile using `esm`, and a webpack
      build through `@quatico/websmith-loader`.
